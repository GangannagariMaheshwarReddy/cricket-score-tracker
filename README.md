***🏏 Cricket Scorer (Offline)***
📌 Project Description

Cricket Scorer is an offline cricket scoring application inspired by Cricbuzz.
This app is designed for local/offline use to manage and record cricket match scores easily without internet connectivity.

The application starts by collecting basic match details such as team names, toss decision, batting/bowling selection, batsmen names, and bowlers names, and then allows ball-by-ball score entry, just like real cricket scoring.

🎯 Purpose

Designed for practice matches, local tournaments, and offline scoring

No live streaming or online APIs involved

Focuses on accurate score tracking and simplicity

⚙️ Features

Enter Team Names

Toss selection (Bat / Bowl)

Select Opening Batsmen & Bowler

Ball-by-ball score updates

Track:

Runs

Wickets

Overs

Strike rotation

Real-time score calculation

Match summary display

Fully offline – no internet required

🛠️ Tech Stack

Frontend: React.js

Language: JavaScript

Styling: CSS

State Management: React Hooks

Usage Mode: Offline (Local)
